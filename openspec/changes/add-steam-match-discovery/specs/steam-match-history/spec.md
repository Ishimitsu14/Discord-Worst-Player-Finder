# Spec Delta

## Purpose

Клиент предоставляет ограниченное чтение последних матчей заданного Steam32 через Steam Web API. Он возвращает кандидатов обнаружения и различимые причины недоступности, не определяя пригодность игры для анализа и не обходя настройки приватности.

## ADDED Requirements

### Requirement: Явное создание без побочных действий

Клиент SHALL получать Steam API key и зависимости явно. Импорт и создание MUST NOT читать окружение, открывать БД, обращаться к сети или запускать фоновые задачи. Пустой ключ и некорректные параметры SHALL отклоняться безопасной ошибкой до отправки.

#### Scenario: Создание клиента
- **WHEN** вызывающий создаёт клиент с ключом и подменённым транспортом
- **THEN** до явного чтения истории транспорт не вызывается

#### Scenario: Недопустимый аккаунт
- **WHEN** передан account ID вне диапазона 1..4294967294 либо строка вместо числа
- **THEN** чтение отклоняется без сетевого запроса

### Requirement: Страница кандидатов истории

Клиент SHALL читать историю только указанного Steam32 и возвращать проверенные match ID, время начала и продолжение страницы. Он MUST NOT требовать отсутствующие в истории длительность, исход или роль игрока и MUST NOT выдавать кандидата за подтверждённый завершённый рейтинговый матч.

#### Scenario: Краткая запись Steam
- **WHEN** успешная история содержит ID и время начала, но не содержит длительность или исход
- **THEN** запись возвращается как кандидат без выдуманных значений отсутствующих полей

#### Scenario: Безопасность числовых идентификаторов
- **WHEN** ответ содержит небезопасный целочисленный match ID или некорректное время начала
- **THEN** страница отклоняется без округления ID и без частичного успешного результата

### Requirement: Ограниченная пагинация

Чтение SHALL принимать явные размер страницы и верхнюю границу match ID. Продолжение SHALL двигаться к меньшим ID без зацикливания. Некорректные счётчики и непродвигающаяся страница MUST NOT запускать неограниченный обход; предел страниц устанавливает вызывающий.

#### Scenario: Следующая страница
- **WHEN** Steam сообщает оставшиеся записи после непустой проверенной страницы
- **THEN** возвращается продолжение ниже минимального ID этой страницы

#### Scenario: Пустая успешная история
- **WHEN** Steam возвращает успешный статус с согласованной пустой страницей и отсутствием продолжения
- **THEN** возвращается пустая доступная история, отличимая от запрета доступа

### Requirement: Закрытая история как отдельный исход

Ответ Steam с API status=15 SHALL обозначать недоступность истории данного аккаунта, включая HTTP 200. Он MUST NOT интерпретироваться как успешная пустая история, отсутствие матчей или отсутствие аккаунта в компании. Неизвестный API-статус SHALL возвращать безопасную ошибку.

#### Scenario: Отказ при успешном HTTP
- **WHEN** HTTP-ответ успешен, но внутри указан status=15
- **THEN** вызывающий получает причину закрытой истории без матчей и без внутренних повторов этого отказа

### Requirement: Ограниченные повторы и общий cooldown

Временные сетевые ошибки, таймауты и HTTP 5xx SHALL иметь конечное число GET-повторов. HTTP 401/403, API status=15 и некорректные ответы MUST NOT автоматически повторяться внутри чтения. HTTP 429 SHALL задавать общий для клиента cooldown с учётом Retry-After и безопасного значения при его отсутствии.

#### Scenario: Лимит Steam
- **WHEN** один запрос возвращает 429 с временем следующей попытки
- **THEN** до этого времени клиент не отправляет запросы других аккаунтов и возвращает различимую причину ограничения

#### Scenario: Временный сбой
- **WHEN** все разрешённые GET-попытки завершаются временной ошибкой
- **THEN** чтение завершается типизированной ошибкой, не переходя на другой источник или бесконечный цикл

### Requirement: Таймаут и отмена

Каждая сетевая попытка SHALL иметь конечный таймаут, включающий чтение ответа. Переданный сигнал отмены SHALL останавливать запрос и ожидание повтора; после отмены новые отправки MUST NOT выполняться. Ограничитель SHALL учитывать каждую фактическую отправку, включая повтор.

#### Scenario: Отмена между попытками
- **WHEN** сигнал отменён во время ожидания следующего GET
- **THEN** следующая попытка не отправляется и ожидание завершается

### Requirement: Ключ не попадает в результаты и диагностику

Ключ SHALL передаваться только фиксированному HTTPS-хосту Steam. Перенаправления MUST NOT передавать его другому адресу. Ошибки, сериализация, результаты и диагностические события MUST NOT содержать ключ, полный URL с параметрами, заголовки авторизации или сырые исключения транспорта.

#### Scenario: Ошибка транспорта с URL
- **WHEN** низкоуровневая ошибка содержит URL запроса с ключом
- **THEN** наружу возвращаются только разрешённые код, операция и безопасные метаданные

#### Scenario: Отражённый ключ
- **WHEN** успешный ответ отражает переданный ключ
- **THEN** ответ отклоняется без возврата его тела и без утечки ключа
