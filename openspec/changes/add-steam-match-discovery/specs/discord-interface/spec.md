# Spec Delta

## ADDED Requirements

### Requirement: Ответ по ID ожидающего кандидата

Обычная команда по match ID SHALL показывать сохранённую задачу или отчёт, если они доступны. При их отсутствии и ожидании данных кандидата текущих настроек SHALL возвращаться приватный статус с ID матча и понятной причиной. Он MUST NOT содержать выдуманные job ID, сроки готовности или анализ и MUST NOT создавать повторную генерацию либо публичную копию.

#### Scenario: Данные ещё не появились
- **WHEN** команда получает состояние ожидания OpenDota для найденного Steam-кандидата
- **THEN** отвечает, что матч найден и ожидаются данные; следующая проверка не выдаётся за гарантированное время готовности отчёта

#### Scenario: Сохранённый отчёт уже существует
- **WHEN** вместе с ожидающим кандидатом доступен прежний допустимый результат нужной стороны
- **THEN** команда показывает прежний результат с его ревизией и доступной ссылкой, а не заменяет его пустым статусом

#### Scenario: Другой контекст публикации
- **WHEN** ожидающий кандидат относится к другим настройкам сервера или канала
- **THEN** его статус не раскрывается как кандидат текущего канала

#### Scenario: Срок ожидания закончился
- **WHEN** данные кандидата не были подтверждены в установленный срок
- **THEN** ответ сообщает необходимость проверки и доступность обычного ручного запроса, не обещая продолжающуюся автоматическую обработку
