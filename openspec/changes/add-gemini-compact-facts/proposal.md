# Proposal

## Why

Пользователь выбрал компактный подход из приложенной спецификации Gemini 3.8 Flash: ключевые игровые показатели, тайминги предметов, benchmarks, героические счётчики и текстовый чат. Прежний контекст последнего матча занимал 56 656 bytes и не содержал чат или permanent_buffs; новый вход должен готовиться кодом без изменения выбора нашей команды по Steam32 ID.

## What Changes

- Добавить явный профиль `gemini-compact-v1` модуля `match-facts`, отдельный от `match-brief-v1/v2`, с пятью игроками уже выбранной вызывающей стороной команды.
- Включить читаемые имена героев/игроков, позицию с источником, KDA, kill participation, net worth, урон, LH/denies, вардинг, ключевые покупки, benchmarks и доступные специфические показатели LC/Lion/Pudge.
- Передавать текстовый all-chat выбранных игроков с автором, временем и проверяемым происхождением; chatwheel исключать. Чат предназначен для roast, обвинения в чате не становятся игровыми фактами.
- Добавить компактный контекст соперников для предусмотренных исходной рекомендацией сравнений экономики и состава; детальные карточки драк в новый профиль не включать.
- Сохранять missing/null/invalid/zero, полные данные локально, точные digests и явное сообщение о переполнении. Цель 2–4 КиБ относится к игровому ядру; лимиты чата и полного входа фиксируются отдельно.
- Новые свободные строки разрешить только в явных полях нового профиля. Старые профили, их digests и настройки по умолчанию сохранить.

## Capabilities

### New Capabilities

- `compact-match-context`: компактный игровой контекст, героические метрики и атрибутированный чат для аналитика Gemini.

### Modified Capabilities

Нет изменений архивированных capabilities: `openspec/specs` пока пуст. Контракты прежних изменений `add-match-facts` и `add-match-facts-summaries` остаются действующими для своих профилей; новое поведение включается отдельно.

## Impact

Модуль 4: `src/match-facts/`, публичные типы/экспорты, версионируемый справочник permanent buffs и профильные тесты. Тонкий локальный facts-адаптер лаборатории должен уметь сохранять новый формат. Выбор стороны остаётся у `match-pipeline`; реализация аналитика описана в соседнем изменении [add-gemini-match-analysis](../add-gemini-match-analysis/proposal.md). Здесь нет сети, платных генераций, рейтинга игроков, Discord, миграции SQLite или переключения VPS.
