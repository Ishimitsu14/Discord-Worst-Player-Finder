# Proposal

Согласованное уточнение после первых разборов: добавить экспериментальный пакет v2 с предполагаемыми позициями, карточками всех доступных драк, равным сравнением пятерых и явной уверенностью выбора. Сохранить v1 и прежние планы. Это развитие лаборатории, без переноса требований в соседние модули и без объявления качества подтверждённым.

## Why

До разработки подготовки фактов и аналитика нужно проверить, какие данные матча позволяют MiMo обоснованно выбирать худшего союзника. Лаборатория даст воспроизводимые эксперименты с ручной обратной связью, чтобы не закреплять непроверенные критерии, дорогой контекст и случайно удачный ответ как поведение бота.

## What Changes

- Добавить локальный корпус рейтинговых матчей с неизменяемыми снимками OpenDota, выбранной стороной, происхождением данных и явными ограничениями полноты.
- Начать с матчей `9044556864` и `9046778399`, затем добавить третий для первых гипотез и расширить корпус ориентировочно до 10–15 матчей с отдельной проверочной частью.
- Хранить ручную оценку пользователя по слотам игроков, допустимые варианты одного/двух худших, подтверждающие факты и случаи, когда уверенного выбора нет.
- Версионировать экспериментальную инструкцию, примеры, схему ответа и два представления одного снимка: полное доступное игровое и сокращённое.
- Добавить явные локальные прогоны `xiaomi/mimo-v2.6-pro` через OpenRouter с сохранением запросов, ответов, ошибок, времени, токенов и известной стоимости.
- Сравнивать варианты на одинаковых матчах, отделять автоматическую проверку ответа от содержательной оценки пользователя и исключать проверочные ответы из настройки инструкции.
- Выпускать отчёт с подтверждёнными наблюдениями, ограничениями и предложениями для `match-facts` и `match-analysis`.

В границы изменения не входят реализация клиента OpenDota, промышленная подготовка фактов и аналитик, автоматическое обнаружение матчей, Discord-команды и публикация, SQLite приложения, обучение весов модели, веб-интерфейс и развёртывание. Экспериментальные преобразования и запросы модели принадлежат только лаборатории; их перенос в приложение требует отдельных изменений.

## Capabilities

### New Capabilities

- `evaluation-lab`: воспроизводимые локальные эксперименты оценки матчей на фиксированных данных, с ручными эталонами, сравнением вариантов контекста и отчётами для следующих модулей.

### Modified Capabilities

Нет. Контракт `opendota-client` используется без изменения; спецификации остальных модулей этим изменением не создаются.

## Impact

- Планируется локальный TypeScript инструмент в том же проекте с файловыми артефактами, без отдельного сервиса и базы данных. Прикладного кода и сборки в проекте сейчас нет.
- Источник матчей — публичный OpenDota API или импорт сохранённого ответа. Готовый клиент переиспользуется при наличии; на исследовательском этапе допустим документированный прямой запрос по существующему контракту.
- Платный внешний вызов — только явный запуск эксперимента через OpenRouter. Подготовка корпуса, проверка входов и сравнение сохранённых результатов работают без ключа и сети.
- Секреты читаются из окружения; локальные снимки, обратная связь и результаты не включаются в предназначенные для Git файлы. Проверочные фикстуры должны быть отдельно обезличены.
- На этапе этой спеки создаются только документы. Матчи не загружаются, MiMo не вызывается, эталоны и качество модели не объявляются проверенными.
