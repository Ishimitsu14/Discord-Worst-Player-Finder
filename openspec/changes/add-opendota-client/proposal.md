# Proposal

## Why

Для разбора игр нужны достоверные данные матча и понятное поведение, когда OpenDota ещё не обработал реплей или временно недоступен. Клиент OpenDota станет общей точкой получения этих данных для ручного запуска, автоматического обнаружения и будущих экспериментов с MiMo.

## What Changes

- Добавить получение страниц истории игрока по Steam32 account ID и матча по match ID.
- Различать базовую статистику и доступность данных разбора реплея, сохраняя отсутствующие значения без подстановки нулей.
- Добавить запрос разбора, чтение состояния задания и ограниченное по времени ожидание обновлённого матча.
- Обработать таймауты, отмену, ошибки API, ограничения частоты и безопасные повторы GET-запросов.
- Добавить небольшой кеш в памяти и объединение одинаковых параллельных запросов.
- Зафиксировать проверяемый контракт, ошибки и тестовые сценарии до реализации.

В границы изменения не входят поиск совместных игр, фильтрация рейтинговых матчей, вычисление производных показателей, оценка игроков, вызовы OpenRouter, Discord, постоянное хранение, развёртывание и отдельная лаборатория оценки.

## Capabilities

### New Capabilities

- `opendota-client`: получение истории и статистики матчей, управление запросом разбора реплея и устойчивое взаимодействие с OpenDota API.

### Modified Capabilities

Нет: проект новый, существующих спецификаций и прикладного кода пока нет.

## Impact

- Появится внутренний TypeScript API для будущих модулей бота. Публичный HTTP API не требуется.
- Единственная внешняя интеграция изменения — `https://api.opendota.com/api`; ключ API необязателен и хранится только в окружении процесса.
- Планируемая реализация использует встроенные `fetch`, `AbortSignal` и тестовый раннер Node.js; отдельный HTTP SDK, Redis и база данных клиенту не нужны.
- Данные двух предоставленных матчей и реальный запрос разбора проверены; результаты приведены в design.md. Критерии оценки и корректность MiMo исследуются следующим этапом. Текущий результат — проект контракта клиента, сценарии и задачи, без реализации.
