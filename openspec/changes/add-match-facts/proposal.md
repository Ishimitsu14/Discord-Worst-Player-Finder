# Proposal

## Why

Разборы лаборатории требуют ручной сборки таблиц и эпизодов, а `compact-v2` всё ещё содержит сотни килобайт данных. Нужен самостоятельный алгоритм, который без ИИ готовит короткий отчёт для интерпретации моделью и сохраняет полный набор проверяемых фактов локально.

## What Changes

- Добавить чистое преобразование снимка OpenDota и выбранной стороны в пакет из полного локального `facts-v1`, короткого модельного отчёта `match-brief-v1`, реестра оснований и манифеста. Оба представления формируются обычным кодом без ИИ.
- В коротком отчёте одинаково представить всех пятерых союзников: роли и источник, ресурсы/вклад, экономику по времени, фазовые показатели смертей и поддержки; сохранить контекст всех доступных соперников и компактные строки всех имеющихся драк.
- Подробную хронологию, карты целей/использований, расширенные карточки и исходное происхождение оставить в полном локальном наборе. В отчёте явно различать агрегирование, локально сохранённую детализацию и отсутствие исходных данных.
- Сохранить различия пропуска, null, нуля и пустого массива, проверяемые формулы и предупреждения о противоречиях; отделить временную близость событий от причинности.
- Передавать модели значения с короткими ID, заранее рассчитанные сопоставления и нейтральные агрегаты без рейтинга игроков. Ссылки модели проверять только среди фактов, действительно включённых в её отчёт; исходные пути/формулы хранить локально.
- Добавить тонкую офлайн-команду лаборатории для получения пакета по уже сохранённому матчу, проверки ссылок и отчёта о размере/времени без ручных скриптов.
- Для match-brief-v1 задать цель 32 KiB и предел 64 KiB точного UTF-8 контекста. Проверить четыре development снимка: отдельно полноту локальных фактов и покрытие обязательных групп короткого отчёта. Переполнение явно останавливает подготовку, без скрытого выбрасывания игроков/драк.

## Capabilities

### New Capabilities

- `match-facts`: воспроизводимая алгоритмическая сводка для аналитика и полный локальный набор игровых фактов с ограничениями и проверяемым происхождением.

### Modified Capabilities

Нет. Основных спецификаций пока нет; лабораторные v1/v2 остаются неизменными. Новый офлайн-вход использует публичный контракт `match-facts` и не меняет правила сохранённых экспериментов.

## Impact

Планируемый код: `src/match-facts/`, сфокусированные тесты и документация модуля; небольшой вызов из CLI лаборатории и повторное использование закреплённого справочника. Зависимости TypeScript/Node.js, Ajv и `node:test` уже установлены; новые сервисы и внешние библиотеки не нужны. В `PROJECT_PLAN.md` обновляется только строка модуля 4.

Вход совместим с полем `data` предложенного `MatchSnapshot` клиента OpenDota; сетевой клиент для реализации преобразования не требуется. Будущий аналитик получает match-brief-v1 и интерпретирует подготовленные наблюдения; инструкция MiMo, схема его ответа и калибровка качества остаются в модулях 5/8. Получение и разбор реплеев, выбор стороны и рейтинговых матчей, кеш готовых анализов, очереди, SQLite и Discord в это изменение не входят. Модуль не ранжирует игроков и не назначает виновного.
