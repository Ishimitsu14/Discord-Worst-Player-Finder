# Проверка клиента Steam

`test/steam.test.ts` проверяет публичный клиент с поддельным HTTP и управляемыми часами: 9 сценариев, реальные API-ключи не нужны.

- Инертное создание, Steam32/размеры/cursor, отказ до HTTP.
- Компактные страницы, пустая история, числовые ID/время, счётчики и продвижение cursor.
- status=15 при HTTP 200 отдельно от пустой истории, неизвестный API status и HTTP 401/403/302 без повторов.
- Два временных GET-повтора, локальные 60 отправок/мин, общий 429 с Retry-After seconds/date/fallback.
- Таймаут чтения тела, отмена HTTP/повторной задержки и очистка таймеров.
- Безопасные ошибки с ключом в исходном URL и отклонение отражённого секрета/плохого JSON.

Команды: `npm.cmd run build`, затем `node --test dist/test/steam.test.js`. Пример README использует те же публичные сигнатуры, проверенные TypeScript в тесте.

Итог реализации на Windows x64/Node v22.14.0: 9/9 клиентских тестов, typecheck/build успешны. Полный набор — 426: 420 pass, 0 fail, 6 Linux-only skip. Инертный импорт отдельно проверен в дочернем процессе с запретом fetch и чтения STEAM_API_KEY; конструктор не запускает HTTP/таймеры. Проверка известных секретов в исходниках/документах/тестах Steam-изменения дала ноль совпадений.
