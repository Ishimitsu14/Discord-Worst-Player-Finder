# Проверка match-facts — 17 октября 2026

Реализованы полный `facts-v1`, алгоритмический `match-brief-v1`, реестр оснований, проверка и офлайн-команда. Сеть/модель при подготовке не используются. Снимки, выходные пакеты и детальный протокол находятся только в игнорируемой `.local/evaluation/`.

## Автоматические проверки

- Windows, Node.js 22.14.0, существующие TypeScript/Ajv/node:test; новых зависимостей нет.
- `npm.cmd test`: 98/98 тестов, включая 27 новых проверок модуля/CLI и 71 прежний тест лаборатории. Итоговый протокол сохранён локально в `match-facts-tests.tap`.
- Typecheck и build проходят. Проверены входы/ошибки, обе стороны/исходы, анонимность, пропуски/нули/пустые коллекции, privacy, закрепление справочника, роли/конфликты, временные срезы и формулы, signed причины изменения ресурсов, фазы, предметы, окна смерти, все карточки, canonical mapping, противоречия, объекты, provenance, версии/digests, ацикличность и только переданные ссылки.
- CLI тестируется при запрещённом `fetch` и пустых ключах: help, готовый пакет, повторы, ошибочный файл ролей, отсутствующий/повреждённый снимок. Все шесть файлов сохранены; minified context проверен. Прерванная запись оставляет каталог без manifest, повтор не перезаписывает артефакты. Диагностика времени не входит в bundleId.
- Независимая проверка отвергает удалённую поддержку/ресурсы одного игрока, исходную карту и потерянную карточку. Переполнение останавливает подготовку, диапазон между 32/64 KiB допустим.
- Песочница Windows запрещает hard links (`EPERM`); файловые тесты/реальные запуски выполнены с локальными разрешениями, штатный atomicWrite не менялся. Linux runtime не проверен.

Нестабильные миллисекунды не являются порогом CI.

Сверены 60 наблюдений: по каждому из 20 союзников положительный вклад, наблюдение смерти в явно выбранной фазе и контраргумент. Значения независимо сопоставлены с raw; это аудит исходных данных, а не эталон правильности выбора худшего. ## Сохранённые лабораторные форматы

Все четыре старых плана прошли проверку checksum своих артефактов. 12 контекстов последнего v1 (`c2283727…`) и последнего v2 (`4f0cc23c…`) воспроизведены текущим кодом и совпали с сохранёнными. `context.ts`, `context-v2.ts`, профили, словарь и старые планы/корпус/эталоны этим модулем не изменяются.

Два более ранних исторических плана проверены по неизменным bytes, но не объявляются регенерируемыми: словарь `2d527c89…` ещё не содержал abilities, а контексты `8d3e8b36…` предшествуют текущему сериализатору v2. Это ограничение прежних артефактов, зафиксированное отдельно; их входы и запросы сохранены. Миграция этих исторических форматов не входит в match-facts.

## Пределы выводов

- Все четыре матча уже обсуждались: это development, независимого holdout нет.
- Полный порядок смертей/покупок/вардов и вложенные карты целей/применений остаются локально. Brief сохраняет фиксированные показатели, фазы и тайминги, но не устанавливает конкретную цель заклинания, позицию, готовность предмета или причинность.
- Сверка положительного/слабого наблюдения и контраргумента не подтверждает сохранение всех прежних интерпретаций: для некоторых выводов потребуется локальная детализация либо признание недостатка данных аналитиком.
- Платных запросов, измерений токенов, стоимости, latency/качества MiMo и независимой пользовательской калибровки нет. Уменьшение bytes не является измерением ускорения модели.
- Подключение короткого отчёта к MiMo остаётся задачей отдельного `match-analysis`; модуль не выбирает худшего и не пишет roast.
