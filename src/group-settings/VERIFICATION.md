# Проверка настроек компании — 17 октября 2026

Реализованы `GroupSettings`, `loadGroupSettings(path)` и `GroupSettingsError` в одной публичной точке `src/group-settings/index.ts`. Добавлены вымышленный пример и [инструкция](../../config/README.md). Общая сборка, зависимости и соседние модули сохранены; существующее исключение `.local/` в `.gitignore` переиспользовано.

## Проверки

- Windows, Node.js 22.14.0; встроенные fs/promises, JSON.parse, BigInt и Object.freeze, без новых зависимостей.
- `npm.cmd run typecheck`, сборка и `openspec.cmd validate add-group-settings --type change --strict --no-interactive` проходят.
- `npm.cmd test`: 165/165 тестов, включая 12 новых и 153 прежних. Полный протокол: `.local/group-settings/tests-11e8ba12-0b6f-4614-b82d-ee87958812db.tap`.
- Проверены абсолютный/относительный путь, пробелы, передача непустого пути без trim, LF/CRLF, один BOM, отсутствие файла/каталог, пустой/оборванный JSON, комментарии, хвостовая запятая и лишний BOM. Управляемый EACCES проверяет одно чтение и безопасную ошибку; отказ прав ОС нативно не воспроизводился.
- Проверены строгий корень и три обязательных поля; неизвестный ключ, в том числе __proto__, отображается только как `$`. Steam32 проверены на обеих границах, одном аккаунте, сохранении порядка, дубликатах с индексом, неверных типах/диапазонах, Steam64/ссылках/никах.
- Discord ID проверены как точные строки, включая значения выше безопасной точности number и границу uint64. Отклоняются числа, пробелы и переводы строк, ведущие нули, знаки, дроби, экспоненты, упоминания, URL, другие цифры Unicode и превышение диапазона.
- Синтетический секрет в значении, имени неизвестного ключа, повреждённом JSON, системной ошибке и пути не попадает в message/issues/сериализацию/stack/cause. Собственных логов нет; категории read-error, invalid-json и invalid-settings различаются.
- Проверены замороженные объект/массив, новый снимок при каждом вызове, сохранение прежнего после изменения/удаления файла и новые данные/ошибка при явной повторной загрузке. Нет кеша, fallback, записи, наблюдения или повторного чтения при ошибке.
- В отдельном процессе без ключей запрещены сетевые вызовы, запись и наблюдение; импорт не читает конфигурацию, а загрузка выполняет одно чтение. Чтение собственного JS-модуля механизмом ESM разрешено отдельно от чтения конфигурации. Пример передан двум тестовым потребителям без реализации pipeline/Discord.
- PowerShell New-Item/Copy-Item и загрузка проверочной копии выполнены в `.local/group-settings/check-9067fe38-cf83-4100-8aca-768597549601/`. Результат: два аккаунта, объект и массив заморожены. Рабочий `.local/group-settings.json` и реальные ID не создавались и не запрашивались.

Полный набор запускался с локальными разрешениями Windows для существующих hard-link тестов лаборатории. Небезопасные обходы атомарной записи не добавлялись.

## Ограничения

В папке проекта нет Git-репозитория: наличие правила `.local/` проверено в файле, фактический `git check-ignore` не выполнен. Git не инициализировался.

Linux runtime пока не запускался; используются переносимые средства Node.js. Интеграции с отсутствующими bootstrap/pipeline/Discord и проверка прав канала не выполнялись. Успешная загрузка означает корректность локального формата. Изменение OpenSpec не архивировалось.
