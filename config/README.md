# Настройки компании

`group-settings.example.json` содержит вымышленные ID без проверки существования. Замените все значения своими в отдельной локальной копии. Загрузчик `src/group-settings/index.ts` читает только явно указанный файл; встроенного пути, чтения окружения и fallback нет. [OpenSpec](../openspec/changes/add-group-settings/specs/group-settings/spec.md), [проверки](../src/group-settings/VERIFICATION.md).

## Локальная настройка

Из корня проекта в PowerShell, если локального файла ещё нет:

```powershell
New-Item -ItemType Directory -Force -Path .local | Out-Null
Copy-Item -LiteralPath config/group-settings.example.json -Destination .local/group-settings.json
```

Откройте `.local/group-settings.json` в редакторе и замените ID самостоятельно. Не копируйте пример поверх существующей рабочей конфигурации. Каталог `.local/` уже указан в `.gitignore`; реальные настройки остаются локально. В этой папке проекта пока нет Git-репозитория, поэтому проверка фактического исключения через Git не выполнена.

Токены Discord, OpenRouter и OpenDota в этот JSON не помещаются: они передаются отдельно через окружение будущего запуска приложения. Пример и загрузчик работают без секретов и сети.

| Поле | Формат |
|---|---|
| steamAccountIds | Непустой массив уникальных чисел от 1 до 4294967294, исходный порядок сохраняется |
| guildId | Десятичная строка от "1" до "18446744073709551615" |
| channelId | Тот же строковый формат; один канал публикации |

Все три поля обязательны; неизвестные поля запрещены. Steam64, строки вместо Steam32, ссылки, дубликаты, дроби и анонимные ID 0/4294967295 отклоняются. Один аккаунт допустим. Discord ID сохраняются точно как строки, включая значения выше безопасной точности number; числа, ведущие нули, пробелы, упоминания и URL не принимаются. Допустим обычный UTF-8 JSON с одним начальным BOM, LF или CRLF; комментарии и хвостовые запятые запрещены.

## Использование

Публичный контракт:

```ts
export interface GroupSettings {
  readonly steamAccountIds: readonly number[];
  readonly guildId: string;
  readonly channelId: string;
}

export function loadGroupSettings(path: string): Promise<GroupSettings>;
```

Вызывающий код импортирует `loadGroupSettings` и `GroupSettingsError` из `src/group-settings/index.ts`, передаёт путь и обрабатывает ошибку до запуска потребителей. Абсолютный путь поддерживается; относительный разрешается относительно рабочего каталога процесса. Пробелы в имени файла сохраняются.

Для проверки примера из корня проекта:

```powershell
npm.cmd run build
node --input-type=module -e "import { loadGroupSettings } from './dist/src/group-settings/index.js'; const settings = await loadGroupSettings('config/group-settings.example.json'); console.log({ accountCount: settings.steamAccountIds.length, frozen: Object.isFrozen(settings) });"
```

Для своей конфигурации замените только путь аргумента на `.local/group-settings.json`. Команда показывает число аккаунтов и признак неизменяемости, без самих ID. В Linux используется npm без .cmd; относительный путь к JSON тот же.

## Снимок и ошибки

Каждый вызов читает файл один раз и возвращает новый объект с новым массивом. Объект и массив заморожены во время выполнения. Изменение или удаление файла не меняет старый снимок; новый явный вызов вернёт новые данные либо ошибку. Глобального кеша, наблюдения за файлом, скрытых повторов, записи и автоматического восстановления нет. В приложении загружайте настройки один раз при запуске; после редактирования требуется перезапуск.

`GroupSettingsError` содержит русское message, code и readonly issues с path/message. Категории: read-error — файл недоступен; invalid-json — синтаксис JSON; invalid-settings — путь или содержимое. Пути ограничены `$path`, `$`, именами трёх полей и steamAccountIds[n]. Неизвестный ключ показывается как ошибка `$`; значения и системные/парсерные исключения не выводятся и не прикладываются через cause. Ошибка любого поля отклоняет весь файл.

## Границы модулей

| Потребитель | Получает | Его ответственность |
|---|---|---|
| match-pipeline | steamAccountIds | Опрос, рейтинговый режим, сторона и минимум два разных аккаунта |
| discord-interface | guildId/channelId | Существование, принадлежность/тип канала, доступ и права публикации |
| operations | Явный путь и результат загрузки | Bootstrap, окружение, секреты, завершение старта при ошибке, перезапуск |
| storage | При необходимости снимок контекста обработки | Задачи и результаты; без второго редактируемого источника этих настроек |

Эти потребители пока не реализованы. Успешная загрузка подтверждает локальный формат, а не существование аккаунтов/канала или права бота. Клиент OpenDota получает Steam32 ID аргументами и самостоятельно настройки не читает. Лаборатория оценки не зависит от этого файла.

Проверки из корня проекта: `npm.cmd run typecheck`, `npm.cmd test`, `openspec.cmd validate add-group-settings --type change --strict --no-interactive`.
